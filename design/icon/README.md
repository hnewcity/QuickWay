# QuickWay icon

The Little Q mark: a speech-bubble Q with two capsule eyes, flat black and white.

- `quickway-icon.svg` / `.png`: app icon, white character on a black tile (1024 × 1024).
- `quickway-mark.svg` / `.png`: black mark on a transparent background.
- `optical-16.svg`, `optical-24.svg`, `optical-32.svg`: small-size variants with adjusted stroke weight and eye size.

The application assets in `desktop/src-tauri/icons/` and `desktop/app-icon.svg` are generated from this design.
