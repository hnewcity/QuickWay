### Fixes

- Windows enterprise sign-in: usage checks no longer fail with `HTTP 401` after Quick renews its session. QuickWay now reads Windows Credential Manager the way Python keyring does, preferring the record Quick keeps up to date over the older `session@` copy that can hold an expired token. Credentials that only exist in the older layout keep working. ([#1](https://github.com/hnewcity/QuickWay/issues/1), thanks @hyyitss-Q)
