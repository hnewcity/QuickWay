### Highlights

- Claude Code and Codex now share one **Coding** tab with a tool switch. Each tool remembers its own model and thinking effort; the project folder is shared.
- The model and thinking-effort picker is a single compact popover: four effort levels on top, the model list below.
- OpenAI-compatible `/v1/chat/completions` and `/v1/responses` endpoints, so Codex and other OpenAI SDK clients can use the same local proxy.
- Diagnostics report you can copy from Settings when a connection or usage check fails.
- Nine interface languages: English, 中文, 日本語, 한국어, Русский, Español, Português, Tiếng Việt, Indonesia.

### Release automation

- GitHub Actions runs the Rust tests, Clippy, the browser UI tests and the release-tool tests on every pull request and push to `main`.
- Windows x64 (NSIS installer, portable executable), macOS Apple Silicon and macOS Intel (disk images), plus the command-line proxy for each platform, are built from the same tested commit.
- A GitHub Release with `SHA256SUMS.txt` is published automatically when a new version reaches `main`.
