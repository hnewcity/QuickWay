QuickWay 0.4.1 adds in-app updates to the desktop app.

### New

- QuickWay checks for a new release at launch and once a day. When one is available, the sidebar shows a notice and Settings shows the new version and its release notes.
- Installed copies download the update, verify its signature, stop the local proxy, install and restart from Settings. Downloads show their progress, and an update cannot start while a request is in progress.
- The portable Windows app and a copy run from the mounted DMG cannot replace themselves; they offer a link to the release page instead.
- Settings can check for updates on request and reports a failed check; background checks stay quiet.

### Verification and downloads

- Windows and macOS verification, lint checks and installer builds run in GitHub Actions before this release is published.
- Downloads include the Windows x64 installer and portable app, macOS Apple Silicon and Intel DMGs, signed update packages, `latest.json` and `SHA256SUMS.txt`.

This is the first version with the updater, so install it by hand once; later versions can be installed from within the app. Quit an older running QuickWay tray instance before starting the new version.
