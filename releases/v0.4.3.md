QuickWay 0.4.3 fixes a disconnect race that could interrupt another client's conversation when both clients had the same chat history.

### Fixes

- Disconnecting a stream no longer removes a newer session saved under the same history. A non-streaming client that leaves before receiving a tool call no longer leaves behind a pending session it cannot resume.
- Concurrent clients can declare tools with the same name (for example, `echo`). QuickWay uses session-specific cloud device names and keeps the same mapping when rebuilding history. This isolates routing; Quick's automatic tool selection can still return plain text instead of a tool call.
- The CLI now reports the actual port when started with `--listen 127.0.0.1:0`. The local API accepts case-insensitive `Bearer` schemes and extra separator spaces; the key itself remains case-sensitive.

### Verification

- Added offline regression tests for overlapping streams, WebSocket tool callbacks and the local HTTP gateway, plus an opt-in OpenAI SDK smoke test for concurrent clients. See the [macOS test report](https://github.com/hnewcity/QuickWay/blob/v0.4.3/docs/QA-macOS-2026-11-22.md) for live checks and their limits.
- GitHub Actions verifies Windows and macOS before publishing the Windows x64 installer and portable executable, Apple Silicon and Intel DMGs, signed update packages, `latest.json` and `SHA256SUMS.txt`.
