QuickWay 0.4.2 makes CC Switch import work without a saved default tier and explains missing cloud tiers.

### Improvements

- Import into CC Switch straight from the dashboard. When no valid default tier is saved, QuickWay uses Smart, or the first available tier if Smart is not offered, and labels the choice as automatic. The saved default tier is left unchanged.

### Fixes

- The tier catalog no longer reports "0 tiers · Synced" when the cloud tiers could not be added. It now says the cloud tiers are unavailable and shows the reason, such as a failed Quick sign-in renewal or an enterprise sign-in, which cloud tiers do not support yet. The tiers return automatically once the sign-in works again.

### Verification and downloads

- Windows and macOS verification, lint checks and installer builds run in GitHub Actions before this release is published.
- Downloads include the Windows x64 installer and portable app, macOS Apple Silicon and Intel DMGs, signed update packages, `latest.json` and `SHA256SUMS.txt`.

QuickWay 0.4.1 installed with the Windows installer or as a macOS app in Applications can update to this version from Settings. Older versions, the portable Windows app and copies run from a mounted DMG need a manual download.
