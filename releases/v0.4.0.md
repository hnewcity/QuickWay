QuickWay 0.4.0 adds Quick cloud tiers and improves real Claude Code and Codex project workflows.

### New

- Choose Fast, Balanced, Smart or Advanced in the desktop app. QuickWay shows the model actually reported by the cloud after a response; a tier does not pin a specific model.
- Use the cloud route with Claude Code, Codex and OpenAI-compatible clients, including streaming replies and native code-mode tools.
- Run an explicit, redacted inference probe with `quickway doctor --probe-model MODEL` when diagnosing a connection.

### Fixes

- Recover a lost cloud session when the client supplies complete history and completed tool results. A retry no longer turns those completed results into a pending-tool HTTP 400; missing results remain an error.
- Preserve user updates that arrive alongside tool results, and handle Claude Code's replay of default tool arguments.
- Present Quick's decision widgets as readable questions and options, and remove internal assistant references from ordinary replies while preserving code examples.
- Keep context usage separate from cumulative cloud usage, and propagate upstream streaming errors instead of reporting incomplete replies as successful.
- Improve Claude Code's cloud-tier model metadata and tool registration for the full client tool catalog.

### Verification and downloads

- Real Claude Code 2.1.302 and Codex 0.167.0-alpha.4.1 each created a runnable project, implemented a follow-up feature and passed 8 independent tests plus direct CLI checks. Codex also completed a forced cloud-session recovery after writing project files.
- Windows and macOS verification, lint checks and installer builds run in GitHub Actions before this release is published.
- Downloads include the Windows x64 installer and portable app, macOS Apple Silicon and Intel DMGs, and `SHA256SUMS.txt`.

Cloud tiers currently require a supported social/AIDP Quick sign-in. Serving models are chosen by Quick and can change between requests. Quit an older running QuickWay tray instance before starting the new version.
